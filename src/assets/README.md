# Earth textures

`src/assets/earth/*` are derived from the Earth textures in the three.js examples
(`examples/textures/planets`, MIT licence, https://github.com/mrdoob/three.js).

- `day.jpg`: daytime colour (2048×1024)
- `normal.jpg`: relief normal map
- `ocean.jpg`: ocean mask (white = water), used for sun glint and for the atlas and hologram looks
- `lights.jpg`: night-side city lights, converted to a single channel
- `clouds.jpg`: cloud density, taken from the alpha channel of the original cloud layer
